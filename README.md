# 📱 Mobile Sales Analysis Dashboard | Power BI

## 📌 Project Overview

The Mobile Sales Analysis Dashboard is an interactive Power BI project designed to analyze mobile sales performance, transaction patterns, customer ratings, payment methods, and brand performance across different cities.

The dashboard transforms sales data into meaningful insights through interactive visualizations, KPI cards, and filters, helping users understand business performance and customer purchasing behavior.

## 🎯 Project Objectives

- Analyze total mobile sales, quantities sold, and transaction volume.
- Compare sales performance across mobile brands and models.
- Understand customer preferences for different payment methods.
- Track monthly sales quantities and daily sales trends.
- Analyze sales distribution across cities.
- Evaluate customer ratings and purchasing patterns.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — KPI calculations and measures
- **Microsoft Excel** — Data source and data preparation

## 📈 Dashboard Features

### 1. Sales Performance Analysis
- Monitored total sales and average sales.
- Analyzed sales trends across different months.
- Compared sales performance across days of the week.

### 2. Brand & Mobile Model Analysis
- Compared sales across Apple, OnePlus, Samsung, Vivo, and Xiaomi.
- Analyzed transaction volume and quantity by brand.
- Identified top-performing mobile models based on sales.

### 3. Payment Method Analysis
- Compared transactions made through UPI, debit cards, credit cards, and cash.
- Visualized the percentage contribution of each payment method.
- Examined customer payment preferences.

### 4. Geographic Sales Analysis
- Visualized sales distribution across multiple Indian cities.
- Used map-based visualization to explore geographic performance.
- Enabled location-based sales comparisons.

### 5. Customer Rating Analysis
- Analyzed the distribution of customer ratings.
- Examined customer feedback patterns.
- Used rating visualizations to understand customer satisfaction.

### 6. Interactive Filters
- Month
- Mobile Model
- Payment Method
- Brand
- Day Name

These filters allow users to explore sales performance across different business dimensions.
